## 1. Как запустить работу в новой сессии Claude Code

```bash
git clone https://github.com/VashikMart/relictum
cd relictum
```
(это публичный репозиторий — он же деплой-репо сайта; приватный `relictum-project`
нужен только владельцу: там лежит файл с закупочными ценами.)
Открыть папку как проект и первым сообщением написать:

> Прочитай CLAUDE.md и HANDOFF.md — это проект Relictum, продолжаем работу. Задача: …

Нужны доступы: GitHub (push в этот репозиторий), **Higgsfield MCP** (генерация фото/видео),
по желанию Google Drive MCP (владелец кидает архивы ссылками) и Canva MCP.

**Ритуал:** работаем → в конце «сохрани в гит» (приватный репо) и/или «задеплой» (публичный сайт).
Ничего не пушится и не публикуется без явной команды владельца.

## 3. Главные правила проекта (не нарушать)

1. **Только реальные экспонаты.** Никаких выдуманных объектов и сгенерированных «под концепт» фото несуществующих предметов. Владелец это уже дважды правил — больно.
2. **Фото объекта = реальный предмет.** Генерация допустима только как img2img с реального фото: меняем окружение (фон, подставка, свет), сам объект — пиксельно неизменен.
3. **Единый студийный стиль.** Все фото каталога — тёплый ivory #F4F0E8 либо чёрная студия. Промпт-канон в CLAUDE.md.
4. **Себестоимость — никогда наружу.** Закупочные цены партнёра не публикуются нигде: ни в этом репо, ни на сайте, ни в PDF. Продажные цены — можно. На сайте у всех объектов «Цена по запросу».
5. **Не выдумывать факты об экспонатах.** Если у Михаила нет данных — «уточняется», а не придуманная цифра.
6. **Деплой только по команде.**
