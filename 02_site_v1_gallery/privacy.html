  • ограничения обработки персональных данных достижением конкретных, заранее определённых и законных целей (исполнение заказа, выдача паспорта объекта, бухгалтерская отчётность);
  • недопущения обработки персональных данных, несовместимой с целями сбора (например, неиспользование данных корпоративных клиентов для розничных рассылок без отдельного согласия);
  • недопущения объединения баз данных, содержащих персональные данные, обработка которых осуществляется в целях, несовместимых между собой;
  • обработки только тех персональных данных, которые отвечают целям их обработки;
  • соответствия содержания и объёма обрабатываемых персональных данных заявленным целям обработки;
  • недопущения обработки избыточных персональных данных по отношению к заявленным целям (Relictum не запрашивает паспортные данные при оформлении заказа на доставку, если это не требуется службой доставки или платёжной системой);
  • обеспечения точности, достаточности и актуальности персональных данных по отношению к целям обработки персональных данных;
  • уничтожения либо обезличивания персональных данных по достижении целей их обработки или в случае утраты необходимости в достижении этих целей.
