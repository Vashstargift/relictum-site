# Дизайн-система печатного каталога RELICTUM

**Data-driven.** Экспонаты — в `catalog_data.js` (WORLDS + EXHIBITS). Генератор
`render_catalog_pdf.js` собирает `catalog_collection_2026.html` (не править руками —
перегенерируется!) и рендерит `RELICTUM_collection_2026.pdf`.
Добавить/поправить экспонат = править `catalog_data.js` → перезапустить генератор.
Каталог = **вся реальная коллекция** (наличие Михаила + лунный метеорит), 28 экспонатов,
у 8 «якорных» есть alive-разворот «встретить живым». Цены НЕ публикуются — везде «Цена по запросу».
Конвейер: скилл `.claude/skills/relictum-catalog-pdf/SKILL.md`. Canva — импорт PDF, см. ниже.

## Формат
- A4 **альбомный** (297 × 210 мм), полный вылет (margin 0), `@page { size: 297mm 210mm }`.
- Рендер: headless Chromium `page.pdf(printBackground, preferCSSPageSize)` — скрипт `render_catalog_pdf.js`.
- Объём: 24 полосы (обложка, манифест, оглавление, 3 дивайдера, 8×2 экспонатных, сервис, финал).

## Типографика
- Дисплей: **Cormorant Garamond** 300–600 + italic (заголовки, латынь, худ. лиды, цены).
- UI: **Inter** 300–600 (текст, кикеры-лейблы).
- Кикер: 8.2pt, letter-spacing .22em, uppercase, 500.
- H1 полосы экспоната: 24.5pt; дивайдер: 40pt; манифест: 33pt.
- Wordmark: Cormorant 400, letter-spacing .5em (+ text-indent той же величины для центровки).

## Анатомия полос
### Полоса-паспорт (светлая, .exhibit)
Сетка `128mm | 1fr`: слева фото `ph_<slug>.jpg` (object-fit cover на всю высоту),
справа: кикер (ID · категория · регион) → H1 → латынь italic → hook (italic, линейка сверху)
→ описание → паспорт-таблица (Возраст/Находка/Размер/Документы, строки с hairline)
→ «Цена по запросу» + примечание → внизу strip из 3 фото 26mm (g_*_1, g_*_2, int_ph_*).
Колонтитул: раздел слева, номер страницы справа.

### Разворот «Встретить живым» (чёрный, .alive)
Сетка `1fr | 116mm`: слева full-bleed кадр живого существа (still_alive_* / beast_*)
с градиентом-тенью к тексту; справа: кикер gold «Встретить живым» → H2 (цитата-хук)
→ 2 абзаца story из promo-data → блок «Эпоха» → внизу «В вашем доме» (миниатюра int_ph_* 34mm + текст).

### Дивайдер раздела (чёрный, .divider)
Full-bleed кадр из чёрной студии (still_black_*), градиент слева, текст внизу слева:
кикер «Раздел N» → H1 (Монументы/Жизнь/Космос) → italic-подводка.

### Обложка / финал
Обложка: still_black_* full-bleed + радиальная виньетка; wordmark + слоган сверху,
«Каталог коллекции · MMXXVI» и оси внизу. Финал: контакты + QR (segno, dark=#C9A96A,
inline SVG c viewBox) + подпись «наведите камеру».

## Медиа-конвенции
- `ph_<slug>.jpg` — каноническое ivory-фото (nano_banana img2img, канон из CLAUDE.md).
- `still_black_<slug>.jpg` — кадр из hero_museum_*.mp4 (ffmpeg, ~2.5 c): чёрная студия.
- `still_alive_<slug>.jpg` — кадр из vid_*.mp4 / era_*.mp4 (~3 c): существо живьём.
- `g_<slug>_1/2.jpg`, `int_ph_<slug>.jpg` — галерея и интерьер с промо-страниц.
- Извлечение кадров: `ffmpeg -ss 2.5 -i <video> -frames:v 1 -q:v 2 out.jpg` → PIL thumbnail 1600, q86.

## Добавить экспонат (чек-лист)
1. Данные уже в `shared/catalog.js` + `16_product_promos/promo-data.js` (интейк по INTAKE.md).
2. Убедиться, что есть ph_*, g_*_1/2, int_ph_*, still_alive_* (если нет — извлечь/сгенерить).
3. В `catalog_collection_2026.html` скопировать пару `<section class="page exhibit">` +
   `<section class="page alive">` внутрь нужного раздела, заполнить из catalog.js/promo-data.js.
4. Добавить карточку в сетку «Коллекция» (.toc-grid).
5. Перегенерить PDF (`render_catalog_pdf.js`), проверить полосы глазами, закоммитить, задеплоить.
6. Обновить Canva-версию: реимпорт PDF или правка соответствующих страниц.

## Canva
Редактируемая копия для ручных правок: Canva → «Импорт» → публичный URL PDF
(https://vashikmart.github.io/relictum/07_product_presentations/RELICTUM_collection_2026.pdf).
Мастер — всегда HTML+данные в этом репо; Canva-копия — для быстрых ручных правок
и адаптаций. Двусторонней синхронизации нет: крупные изменения делать в мастере
и реимпортировать.

## Масштабирование на другие бренды
Дизайн-система параметрична: заменить токены (§Токены), пару шрифтов, wordmark
и медиа-конвенции — структура полос (паспорт/повествование/дивайдеры/сервис/финал)
переносится как есть. Для нового бренда: скопировать HTML, заменить `:root`-блок
и контент, сохранить сетку и типографическую шкалу.
