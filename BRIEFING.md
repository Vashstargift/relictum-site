# RELICTUM — мастер-брифинг (состояние на 07.10.2026)

> Очищенная копия для репозитория: без адресов сервера, ключей, точек API и учётных записей.
> Эти детали — у владельца и в локальной памяти рабочей машины. Читать вместе с `CLAUDE.md`,
> `NEXT-SESSION.md` и `16_product_promos/HOUSE-RULES.md`.

**Что это.** Люксовый дом редких природных артефактов: скелеты и черепа динозавров, метеориты, аммониты, минералы, мамонтовая фауна. Слоган «Роскошь вне времени». Сайт **https://relictum.gallery** (российский хостинг). Галерея — ТЦ «Гименей», Москва, ул. Большая Якиманка, 22, ежедневно 10:00–22:00. Коллекция: около 140 лотов, из них около 120 на витрине (≈90 в наличии, остальные под заказ), прочие скрыты как архив.

## 1. Где что лежит
- **Репозиторий** — этот. Рабочий remote для пуша указан в локальном клоне; старый оригинальный репозиторий не трогать. Репозиторий **публичный**: никаких ключей, закупочных цен и выгрузок CRM.
- **Исходники витрины:**
  - `02_site_v1_gallery/` — страницы, `style.css`, `_collection.tpl.html` (шаблон посадочных);
  - `16_product_promos/exhibit.html` — шаблон страницы лота;
  - `15_concepts/` — эры и «Страта» (стили — `shared/chrome.css`, а не `style.css`);
  - `shared/` — `nav.js`, `shop.js`, `i18n.js`, `i18n-lots.js`, `focus.js`, `catalog.js`;
  - `09_admin/` — сборщик, `landing_copy.json`, `faq.json`, `i18n_pages.json`, `i18n_static.py`, `journal_meta.json`, `crm_sync.py`.
- **Сборщик** `09_admin/build_public_site.py` → папка `public/` (не в git). В нём: шаблон `.htaccess` (редиректы), форма заявок, узел публикации CRM, правила посадочных (`LANDINGS`, `UNLISTED_LANDINGS`), перелинковка (`SECTION_LINKS`, `FOOTER_SECTIONS`), карточки лотов в статьях (`JOURNAL_LOT`), запасные описания языковых версий, список файлов для метки версии `?v=` (`DATA_FILES`).
- **Источник правды по лотам** — CRM StarGift (вкладка «Relictum» и «Склад → Relictum»). Файлы `shared/catalog.js` и `promo-data.js` в репо — только снимок, их подтягивает `crm_sync.py pull`.

## 2. Публикация и выкладка
1. Лоты правятся в CRM. `python3 09_admin/crm_sync.py publish` — узел на сайте пересобирает русские страницы лотов, `catalog.js`, sitemap; сам ставит русским страницам лотов hreflang на языковые версии и сохраняет языковые лоты в sitemap.
2. Шаблоны и страницы: `crm_sync.py pull` → `build_public_site.py` → бэкап на сервере → rsync **без `--delete`**, исключая `shared/catalog.js`, `objects/promo-data.js`, `send.php` (их пишет сервер) → снова `publish`.
3. Кэш стилей и скриптов — 7 дней; метка `?v=` = хэш `DATA_FILES` (включая словари переводов). Если выкладываются не все страницы — метку нужно обновить во всех html на сервере.
4. Проверка — headless Chromium и WebKit (Safari) через Playwright, профили iPhone. Ложные тревоги: тег `<base href>` на языковых страницах, Вебвизор Метрики в WebKit.

## 3. SEO / GEO
- Страницы лотов `/objects/<номер>-<слаг>.html`: серверный HTML для роботов, JSON-LD Product (+ параметры лота, цена только если есть) и BreadcrumbList; архивные — `noindex,follow`.
- **Заголовок лота:** «Название, вес|размер — R–XXXX, RELICTUM» — без дублей. Описание — первый абзац (≤160 знаков).
- **Языковые версии /en /zh /ar** (≈115 страниц на язык; версия создаётся, если русского осталось ≤10%), hreflang ru/en/zh-Hans/ar/x-default. Метаописание языковой страницы лота — перевод первого абзаца, иначе шаблон с номером лота.
- `sitemap.xml` (без noindex-страниц), `llms.txt` (разделы, посадочные, журнал, лоты), robots, 301 `/index.html → /`, «терпимые» адреса лотов.
- Страницы: главная, каталог, 22 посадочные (две — «Челябинский метеорит», «Зуб мегалодона» — доступны по адресу, но в списки подборок не выводятся), хаб подарков, «Частые вопросы», журнал (16 статей), эры, «Страта». Яндекс Метрика с целями стоит на всех страницах. Файл подтверждения Яндекс Вебмастера в корне сайта не удалять.

## 4. Переводы — главный подводный камень
Перевод привязан к русской строке **дословно**. Правишь русский текст — правь ключ и перевод:
- страницы, посадочные, статьи, вопросы-ответы → `09_admin/i18n_pages.json`;
- интерфейс и эры → `shared/i18n.js`;
- тексты лотов (абзацы описаний, анонсы, «Как нашли», факты, возраст) → `shared/i18n-lots.js` — словарь ручной, генератора нет, дополнять парами «русский → [en, zh, ar]».
Иначе строка останется русской, а страница может выпасть из языковой версии.

## 5. Витрина — решения владельца
- **Подборки:** основная сетка «Лоты в наличии» без лотов «Под заказ»; ниже отдельный блок «Также в коллекции — Под заказ». Количество экспонатов в подписях не показывается. «Частые вопросы | Как выбирать» — две колонки на ПК, «Смотрите также» под ними.
- **Каталог:** на телефоне 2 колонки, полоса быстрых разделов, «Показать ещё» по 24; кнопка фильтров «Искать».
- **Страница лота:** на телефоне фото → название → цена → кнопка; закреплённая полоса покупки с WhatsApp.
- **Шапка и меню телефона:** корзина (и избранное на широких экранах); в меню иконки, разделы, языки, контакты.
- **Подвал:** «Коллекции» ведут на посадочные; «Дом»: О доме, Интерьеры, Экспедиции, Эры, Журнал, Пресса, Частые вопросы.
- **Журнал:** одна колонка 840 px, текст 16 px; карточка лота внутри статьи с живой ценой; у каждой рубрики своя рекомендованная статья.
- **Главная:** цены карточек подтягиваются из каталога.

## 6. Правила дома (кратко)
- Тексты лотов — люкс-регистр и научная точность; без «уникальный»; без темы подлинности в карточках (исключения по решению владельца — блок ценностей на главной и подписи подборок); без слова «лот» в витринных текстах; периоды пишутся полностью, эра ≠ период.
- Витринные тексты (заголовки, вводные, CTA) — «как говорят люди», через ChatGPT.
- Фото — только каноны (вертикаль 4:5 на бежевом фоне) и профессиональная съёмка галереи; сырые снимки — только референс.
- Забронированные номера: R–0102, R–0210, R–0625…R–0629. «Пара» разных предметов — две карточки.

## 7. Проверки текстов и SEO
- Научная вычитка (07.10.2026): тексты сайта и лотов выгружаются в корпус, проверяются ChatGPT и независимым агентом Claude, свежие аукционные факты сверяются поиском; правки лотов — скриптом с проверкой «вхолостую» и бэкапом.
- SEO-обход sitemap: canonical, noindex, title/description и их дубли, H1, JSON-LD, hreflang, внутренние ссылки.
